## dsops — DevOps library

[`devops-lib/`](devops-lib/) contains **dsops**, a reusable toolkit for distributed systems and
data engineering: retries and circuit breakers, typed config, structured logging, Prometheus
metrics, health probes, consistent hashing, distributed locks, idempotency, and a resumable DAG
pipeline runner with data-quality gates. See [devops-lib/README.md](devops-lib/README.md).
