## dsops — DevOps library

[`devops-lib/`](devops-lib/) contains **dsops**, a reusable toolkit for distributed systems and
data engineering: retries and circuit breakers, typed config, structured logging, Prometheus
metrics, health probes, consistent hashing, distributed locks, idempotency, a resumable DAG
pipeline runner with data-quality gates, and connectors for partitioned datasets (local or S3)
and SQL tables (Postgres, SQLite). See [devops-lib/README.md](devops-lib/README.md).
